Apa Itu Algoritma?

Algoritma adalah langkah-langkah sistematis untuk menyelesaikan suatu masalah.
Sebelum membuat progam, progammer sebaiknya memahami masalah dan solusi yang akan dibuat.

Langkah Membuat Algoritma

  1. Memahami Masalah
  2. Menentukan Input
  3. Menentukan Proses
  4. Menentukan Output
  5. Menulis Langkah Penyelesaian
  6. Menguji Solusi

Struktur Data Algoritma

  • Sequence
  • Selection
  • Intertion

Contoh Stuktur

  • Sequence
    • Input
    • Process
    • Output
  • Selection
    • IF
    • IF ELSE
    • SWITCH
  • Intertion
    • FOR
    • WHILE
    • DO WHILE

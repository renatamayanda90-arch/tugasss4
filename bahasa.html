Mengenal Bahasa Pemrogaman

Bahasa pemrogaman digunakan untuk memberikan intruksi kepada komputer. Setiap bahasa mempunyai karakteristik dan kegunaan yang berbeda.
Seorang progammer sebaiknya memahami konsep pemrogama,bukan hanya menghafal sintaks.

Contoh Bahasa Pemrogaman

  1. Phyton
  2. Java
  3. JavaScript
  4. PHP
  5. C++
  6. Dart

Kategori Bahasa

  • Web
  • Mobile
  • Desktop
  • Game
  • Data Secience

Istilah Bahasa Pemrograman

Sintax
Aturan penulisann kode dalam sebuah bahasa pemrogaman.
Variabel.
Tempat untuk menyimpan sebuah nilai atau data.
Function
Kumpulan instruksi yang dapat dipanggil untuk melakukan tugas tertentu.
Library
Kumpulan kode yang dapat digunakan kembali dalam progam.

Tips Memilih Bahasa

Jika ingin membuat website, kamu dapat mempelajari HTML,CSS,dan JavaScript.
Jika tertarik dengan data, kamu dapat memulai belajar Phyton.
Jangan mencoba mempelajari semua bahasa sekaligus.Fokus pada satu bahasa terlebih dahulu.
